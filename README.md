# ido

## אופק האירועים

`index.html` — a real-time black hole in the browser. A single WebGL fragment shader integrates Schwarzschild null geodesics per pixel (gravitational lensing, photon ring), with a Doppler-beamed, redshifted accretion disk. No build step, no dependencies: open the file.

## המהפך

`card.html` — a two-sided holographic competitor card: athlete on the front, engineer on the back. Add a stage photo locally; nothing is uploaded.
