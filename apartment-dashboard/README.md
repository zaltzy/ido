# מוכרים את הדירה

דשבורד למעקב אחרי פרסומי הדירה (יד2, פייסבוק, אינסטגרם) ולניהול פניות.

- `index.html` הוא מקור הדף שמפורסם כ-Artifact ב-claude.ai (הנתונים נשמרים במסד הנתונים של ה-Artifact, לא בקובץ).
- אוספים: `config/main` (פרטי דירה, טקסטים, נמענים), `channels` (מקומות פרסום וקצב חידוש), `leads` (פניות).
- מיילי תזכורת נשלחים ממשימות מתוזמנות ב-Claude Code (בוקר וערב, שעון ישראל).
